# 08.008 — Factual Career Positioning

Task: `task.skillcertify.08.008`

Human-approved positioning:

`Frontend / Fullstack Developer`

Interpretation:
- Frontend is the primary and strongest evidence-backed professional anchor.
- Fullstack is an expansion direction supported by backend-oriented project evidence.
- Fullstack must not be represented as proven production-grade end-to-end operation.

## Primary technical core

- React
- Next.js
- TypeScript
- JavaScript
- frontend architecture and implementation
- testing and quality-oriented workflows
- Git/GitHub development workflow

## Expansion evidence

- ASP.NET / .NET backend project work exists in separately inspected repositories.
- Controllers, services, models, data/migrations and related backend structures exist in inspected project evidence.
- Database-oriented configuration and Entity Framework dependencies exist in inspected evidence.

## Required boundaries

- Do not claim production deployment unless separately established.
- Do not claim production database persistence unless separately established.
- Do not claim frontend-backend end-to-end integration unless separately established.
- Do not claim business ROI, commercial impact or quantified outcomes without source evidence.
- Do not claim sole ownership of complete systems without explicit authorship evidence.
- Do not claim professional employment experience from repository evidence alone.
- Do not describe security remediation as historical secret eradication.
- Do not state that exposed credentials were rotated or invalidated without evidence.

## Positioning rule

Use Frontend as the primary recruiter-facing strength and Fullstack as credible technical expansion, without inflating evidence beyond what the inspected sources establish.
